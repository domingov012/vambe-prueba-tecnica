# Vambe Frontend

Vanilla-JS Vite SPA for the Vambe transcript-insights app.

```bash
cd frontend
npm install
npm run dev      # http://localhost:5173
```

- **Data Upload** (`/`) — upload a CSV of client meeting transcripts, view
  LLM-enhancement jobs.
- **Dashboard** (`/dashboard`) — Chart.js charts over processed transcripts
  (scaffold, placeholder data).

Backend is not wired up yet. See `CLAUDE.md` for structure, conventions, and
step-by-step backend-wiring instructions.
